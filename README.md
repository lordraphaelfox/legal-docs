# legal-docs

Documentos legais públicos da Inuman Games (política de privacidade, termos),
hospedados por GitHub Pages. Uma pasta por jogo — o documento muda de jogo pra
jogo, o repositório é o mesmo.

- `sinete/privacy.html` — política de privacidade do Sinete
- `sinete/delete-account.html` — como pedir a exclusão da conta do Sinete
- `sinete/presskit/` — press kit do Sinete (imprensa e criadores), com `sinete_presskit.zip`
